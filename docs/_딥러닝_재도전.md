## 읽는 법

**① 피처가 신호를 덮었다 — 제일 큰 원인.**
카운트 비율 하나만 주면 mlp 가 **0.710**. 42개 피처 + 공장 one-hot 을 얹으면 **0.495** 로 떨어지고
sd 가 0.111 → 0.238 로 벌어진다. 피처 ablation(`docs/_피처_ablation.md`)에서 39개 회귀 피처의
기여가 +0.008 이었던 것과 같은 이야기다 — 그 피처들은 거의 노이즈고, 정규화가 약한 학습기가 과적합한다.
Ridge 는 L2 가 세서 견뎠다.

**② 구조를 안 줬다.**
`escape = 보고 × κ` 는 검출률 정의에서 나오는 항등식이지 학습할 관계가 아니다.
`deep_kappa` 는 `log(escape) = log(internal_hat) + g(·)` 로 그 구조를 모델 안에 박았다.
결과 **0.409 → 0.746**. 못 배운 게 아니라 배울 재료를 안 준 것이었다.

**③ 남은 0.078 은 κ 추정 방식이다 — 그리고 여기서 conjugate 가 이긴다.**
온라인 갱신 때문이 아니다. `two_stage — κ 고정`(deep_kappa 와 완전히 같은 조건)이 **+0.824** 로
온라인 판과 같다. 즉 비교는 공정했고, Gamma-Poisson conjugate 가 gradient descent 를 이긴 것이다.

이유는 **shrinkage 를 조절하는 방식**이다. conjugate 의 사후분포는
`Gamma(a₀ + Σk, b₀ + Σ노출)` 이라 **노출에 비례해 자동으로** 소표본 공장만 pooled 로 당긴다.
weight decay 는 관측이 많은 공장도 똑같은 세기로 당긴다. 이걸 고치려면 공장별 감쇠를
노출에 비례시켜야 하는데, 그건 **conjugate 사후분포를 gradient 로 재구현하는 것**이다.

**④ 콜드스타트에서도 안 이긴다.**
`deep_feat`(공장 identity 대신 공장 수준 집계 6개로 κ 를 예측 — conjugate 가 못 하는 일)은
**0.707 · sd 0.297** 로 two_stage 0.813 보다 나쁘다. 공장 9곳으로 6개 피처를 적합하니 과적합이다.
`deep_embed` 는 신규 공장에 pooled 를 주므로 two_stage 와 같은 값(0.813)이 나온다 — 같은 일을 한다.

## 결론

**딥러닝이 진 이유는 라벨 수 하나가 아니었다.** 셋이다 — 피처가 노이즈였고, 구조를 안 줬고,
κ 추정에서 conjugate 가 유리했다. 앞의 둘은 고쳤고(0.409 → 0.746), 셋째는 구조적이다.

**재도전 조건도 다시 써야 한다.** 「라벨 몇 건부터」는 ③만 겨냥한다.
①은 라벨이 10배가 돼도 안 없어진다 — 피처에 정보가 없는 것은 표본 문제가 아니다.

1. 피처에 실제 신호가 생겼을 때 — ablation 에서 층별 기여가 **+0.05** 를 넘으면. 지금 +0.008
2. 집계를 풀었을 때 — `cell_daily` 10,503행을 오더당 6개로 압축하고 있다. 시퀀스가 유일하게
   남은 자리다. 다만 집계 피처 기여가 0인 걸 보면 시퀀스에도 없을 가능성이 크다
3. κ 를 상수가 아니라 함수로 봐야 할 때 — 검출률이 제품·시기에 따라 변한다면.
   그때는 공장 수가 12곳보다 훨씬 많아야 한다(콜드스타트 결과가 그 하한을 보여준다)
